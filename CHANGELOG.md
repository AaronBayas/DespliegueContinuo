# Changelog

Todos los cambios relevantes del proyecto se registran aquí. El formato sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y el proyecto usa [Versionado Semántico](https://semver.org/lang/es/).

## [1.0.0] - 2026-11-12

### Agregado
- Formulario para registrar incidencias (título, descripción, reportado por, prioridad y estado).
- Validación de campos obligatorios y de catálogos.
- Listado de incidencias en tabla con etiquetas de color por prioridad y estado.
- Persistencia en `localStorage`.
- Pruebas unitarias y validación de estructura.
- Flujo de GitHub Actions que valida y despliega en GitHub Pages.
