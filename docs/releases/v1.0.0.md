## Sistema de Registro de Incidencias v1.0.0

Primera versión estable. Permite registrar incidencias y verlas en un listado.

### Nuevas funcionalidades
- Formulario de registro con título, descripción, reportado por, prioridad (Baja, Media, Alta) y estado (Abierta, En progreso, Cerrada).
- Validación de datos antes de guardar: título de 5 a 80 caracteres, descripción de al menos 10 caracteres y reportante obligatorio.
- Tabla de incidencias ordenada de la más reciente a la más antigua, con etiquetas de color.
- Los datos se conservan en el navegador mediante `localStorage`.

### Infraestructura
- Pruebas unitarias con `node --test`.
- Script `npm run validar` para revisar la estructura del sitio.
- Workflow de GitHub Actions que valida y despliega en GitHub Pages en cada push a `main`.
